## What the App Does

This is an interactive Neural Network visualizer covering all 17 topics.

You can:
- Change architecture, activation function, optimizer from sidebar
- Click Train and watch the network learn in real time
- See loss curves, gradient flow, decision boundary
- Test Perceptron vs MLP on XOR problem
